Learning objectives

  • State what machine learning is and is not, and match supervised, unsupervised, deep and reinforcement learning to the problem each one fits;
  • Separate prediction from causation, and explain what a held-out score can and cannot establish;
  • Diagnose overfitting and underfitting with learning curves, and choose between more data, stronger regularisation and a simpler hypothesis;
  • Run a clean experimental protocol: train/validation/test discipline, cross-validation without leakage, and metrics that match the decision — including thresholds and calibration;
  • Compare the main supervised and unsupervised learners, including regularised regression, k-NN, SVM, trees and ensembles, PCA, k-means and Gaussian mixtures;
  • Explain what a neural network computes and how reinforcement learning differs, and deliver a model responsibly with a model card, an explanation and a leakage audit.

Key distinction carried through the lecture

A predictive model answers what will happen; a causal model answers what happens if we intervene. The lecture keeps both in view: out-of-sample error is the criterion for prediction, but it cannot identify an effect — that argument returns in Week 7 and in the project's identification section.
