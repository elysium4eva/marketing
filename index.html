Teaching Schedule

Six lectures covering the data-analysis pipeline from raw sourcing to marketing applications.

WeekLectureKey topicsReading / deliverable

Week 2L2 Data SourcingFoundations of data science: data types (numeric/categorical, cross-section/time-series/panel), structured and unstructured data, sources (internal, open data, third-party DaaS, APIs, scraping), primary data (surveys, interviews, experiments, A/B tests); 2026 topics: data contracts and data products, open table formats, vector databases and embeddings, data compliance, synthetic data and labelling quality, the legal limits of scrapingLecture 2 handout; Kaggle Learn; Assignment 1 due
Week 3L3 Data PreparationFive characteristics of data quality, append/merge/join and join types, a five-step cleaning recipe, missing-data mechanisms (MCAR/MAR/MNAR) and imputation, outlier detection, reproducible preprocessing pipelinesMcKinney ch. 7–8; sample code and data on the Code page
Week 4L4 Data Description & VisualizationMetadata standards, descriptive statistics (central tendency, spread, distribution, correlation), chart choice and the grammar of graphics, Power BI / Tableau dashboards; 2026 topics: AI-assisted charting (text-to-chart), misleading charts, accessibility and narrative visualisationRahlf (2019); Power BI / Tableau Public exercise

Assessment

Grading

10% class presentation + 90% research project (choose three of four big-data analytics projects; teams of up to two). The report must include the main steps, the methods, the code, the basic results and their interpretation.

AI use declaration

Every submission must declare the AI tools used (model name, version, date), their purpose, the key prompts, and how the output was verified. Submitting unverified model output is academic misconduct; declaring proper use costs no marks.
