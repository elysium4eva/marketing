How to run

cd code
pip install -r requirements.txt
python run_all.py          # every chapter
python lecture05/run_all.py  # Chapter 5 only

Scripts are numbered in the order they appear in the slides (l5_01 is the first code frame of Chapter 5). Each writes its outputs to the folder it reads from, so a re-run reproduces the figures and tables on the slides.
