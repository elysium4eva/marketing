# Data Analytics in Marketing - course site (English)

Course website for **Data Analytics in Marketing** (Shenzhen University, 2026).
Live at <https://elysium4eva.github.io/marketing/>.

This is the English-language companion to the Chinese course site
[Big Data Analytics](https://elysium4eva.github.io/bigdata/). It covers the
data-analytics part of the Chinese course: Lectures 1-5 and 15 (six lectures),
translated and adapted into English.

## Contents

- `index.html` - course home (info, schedule, lectures, assessment, reading)
- `syllabus.html` - full syllabus with AI-use policy
- `lecture-01.html` - Lecture 1 detail page with embedded slides
- `code.html` - browsable gallery of all example programs
- `files/` - lecture slide PDFs (Beamer, English)
- `code/` - runnable Python examples (Lecture 1 data types; Lecture 3 workflow; Lecture 4 statistics)
- `data/` - sample data generated by the examples
- `figures/` - figures generated by the examples

## Running the examples

```bash
pip install -r code/requirements.txt
python code/run_all.py            # Lecture 1 data-type examples
python code/lecture03/run_all.py  # Lecture 3 analytics workflow
python code/lecture04/run_all.py  # Lecture 4 statistical inference
```

Outputs are written to `data/` and `figures/`.
